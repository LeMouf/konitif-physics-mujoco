# Release procedure

This is an optional provider of @konitif/physics, not a second Physics contract authority. No engine binary, robot profile or asset is included.

Build, test, and verify the exact archive in native Node ESM and strict NodeNext before release. Merge reviewed source into main before tagging the exact version. Publication stays disabled until npm maintainer bootstrap and the trusted publisher for LeMouf/konitif-physics-mujoco, publish.yml, environment npm-release are configured.
